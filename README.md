# Neutrino Physics

This repository contains the source tex code and the final printed document of a brief report on neutrino physics.

As it is clear from the preface, the report has been written as a consequence of the needing of a general introduction to neutrino physics in their beyond-the-standard-model features, such as neutrino oscillations and neutrinoless double beta decay.

The report is largely based on my Master Thesis chapters and it is obviously biased by it. 

The report is not complted yet, as I plan to add a signficant part to the first chapter in order to include also Standard Model physics of neutrinos. 

If you find any error, typo or something that is not clear (or completely wrong) please write me!
